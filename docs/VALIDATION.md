## Reproduction

- Checksums: `shasum -a 256 -c MANIFEST.sha256` from the package root.
- Traceability: `python3 scripts/generate-traceability.py` from the repository root; the script rewrites `docs/00-sot/traceability-matrix.md` deterministically and fails on unknown requirement IDs.
- Schema and example validation: Python 3 with `jsonschema` (4.26.0, Draft 2020-12). Every `schemas/*.json` passes `check_schema`; every `examples/*.json` (plus `examples/config.yaml` after YAML parsing) validates against its schema, with the local schemas pre-registered so URN-based cross-document `$ref` values resolve.
